# 莘县厂房屋顶光伏测试图片包

本包包含 **9 张赛题组提供的同一现场原图**和 **1 张模拟项目备案信息单**。照片来自 `赛题资料/补充内部材料/01.jpg` 至 `09.jpg`，仅复制并改名，未修改像素。备案信息单所有字段均为测试构造，没有真实备案效力。

## 对照赛题要求

| 材料 | 文件 | 说明 |
|---|---|---|
| 电站全景（≥2张） | 04、05、06 | 俯拍和斜拍；可见彩钢瓦屋顶及周边环境 |
| 屋顶连接处 | 07 | 可见组件压块/连接节点 |
| 屋顶下车间 | 01、08 | 可见钢结构和物料堆放 |
| 电气系统/逆变器 | 09 | 逆变器外观及接线，铭牌型号不可读 |
| 备案信息 | 10 | 模拟字段，便于 OCR 与交叉验证 |
| 其他 | 02、03 | 组件近景和厂区外围 |

## 测试时应注意

1. 部分照片水印日期为 **2026-05-04**。若按 **2026-10-04** 起保，已超过 PDF 所述起保前 15 日要求；系统应提示补拍。未带日期水印的照片应提示补充带水印照片。
2. 08 可测试车间卷材/袋装物料识别，但照片本身不能确认物料燃点、危化属性或是否属于高火灾风险行业。
3. 04、06 可见邻近农田。厂房屋顶与农业用地相邻，不等同于项目本身为农光项目；需要结合备案类型及实际土地/建筑用途判断。
4. 09 缺少可读的逆变器/组件铭牌型号；组件型号→抗灾参数→气象风险链路应输出“缺资料”，不要编造型号。
5. 缺少女儿墙/防雷引下线、接地排、配电柜及并网许可/调度协议等清晰照片，适合测试缺材提示，不应作为完整真实投保材料。

模拟备案字段为：项目名称、项目类型、项目单位、被保险人、建设地点、被保险地址、备案编号、装机容量、备案日期。其中项目单位名称和区县参考照片水印；具体项目名、编号、装机容量和日期均为模拟。
