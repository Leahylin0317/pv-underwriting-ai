# 赛题 PDF 要求覆盖矩阵

本表将赛题 PDF 的业务要求对应到当前代码。**已实现**表示代码路径和规则已存在，不代表模型效果已通过比赛盲测；**保守待核**表示数据不完整时转补件或人工审核；**需业务确认**表示官方规则、阶段口径或标注材料缺失，不能自行补造。

| 赛题要求 | 当前实现 | 状态与边界 |
|---|---|---|
| 仅承接屋顶、车棚类分布式光伏；排除集中式、林光、渔光、滩涂等项目 | 项目类型校验；备案/并网 OCR 关键词拒保 | 已实现。OCR 低置信度或文本缺失仍需补件/人工核验。 |
| 至少 5 张图片、2 张全景（正面平视和俯拍）、备案证及指定材料 | 整案材料清单、图片数量和全景视角检查 | 已实现。视角需上传方标注或人工确认，不能仅凭文件名推断。 |
| 图片可打开、清晰、足以判断 | 文件格式及可解码检查；分辨率、亮度、拉普拉斯清晰度预检 | 已实现基础质检。预检为启发式，不是模型置信度，也未用完整 A/B/C 样本校准。 |
| 全景识别周边禁保环境；严重遮挡拒保、轻微遮挡或通道受阻提示 | 8 类环境风险覆盖门槛；不确定时补拍；严重遮挡拒保；轻微遮挡和通道异常提示 | 代码规则已实现。召回率与拒保零漏检须用完整标注包验证。 |
| 全景照片带日期/经纬度水印，且拍摄日期满足 15 日要求 | 检查水印状态、日期、坐标和拟起保日期 | 已实现规则校验；水印 OCR 效果需真实样本验证。 |
| 屋面连接方式、通道、女儿墙/护栏、排水检查 | 视觉检查项及规则提示 | 已实现。缺少明确检查结果时不自动放行，要求补充或人工复核。 |
| 识别车间易燃、危险物品；高火险行业按规则加费或拦截 | 视觉检查易燃/危险物；行业清单支持 JSON 配置，匹配后检查加费确认 | 部分可执行。官方高火险行业清单和加费/拦截规则未提供；当前空清单会触发人工审核，不会默认认为安全，也不会编造费率。 |
| 备案/并网材料 OCR，禁用词、项目主体/被保险人和地址一致性核验 | OCR 字段抽取、禁用词检查、同文件及跨文件字段交叉核验 | 已实现基础比对。地址写法差异可能产生人工复核提示，不会据此自动拒保。 |
| 电气检查按赛题阶段要求执行；中期发现裸露且无防护电缆时拒保 | 裸露无防护电缆风险类别及拒保规则 | 规则已接入；中期检查默认关闭，须业务确认后修改规则配置启用。 |
| 组件、逆变器和汇流箱信息识别；结合风、雹、雪数据判断抗灾能力 | OCR/设备清单解析、组件目录查询、风速评估；降雪量作为气候背景展示；汇流箱密封/熔断器/浪涌保护器检查 | 部分可执行。正式组件目录、风/雹/雪能力参数及官方评估阈值缺失；冰雹和结构雪荷载缺少可靠数据时输出未知并转人工，不推算虚假数值。 |
| 监控覆盖满足条件时可享优惠 | 可识别监控覆盖候选并要求按正式条款人工核验 | 已实现保守流程。正式优惠条件、折扣率未提供，因此不自动折扣或计算保费。 |
| 阶段二加分项：背板鼓包/变色、支架锈蚀/变形、防水层、危险工艺、洁净车间、消防 | 可配置的阶段二视觉检查项和风险提示 | 检查项已接入；模型召回效果未测。阶段开关与具体阶段业务口径需确认。 |
| 输出逐材料结论、风险证据/位置、自然灾害量化信息和综合建议 | 结构化核保结果与 Markdown 报告，保留规则、证据和可用的坐标框；灾害数据带未知状态 | 已实现报告链路。缺失的灾种数据不会伪造；报告不代替授权核保人最终决定。 |
| 高风险环境识别率不低于 90%，拒保场景零漏检；按 A/B/C 验收 | 评测脚本支持按数据集统计结论、风险召回、OCR 和定位指标 | 评测工具已实现，目标尚未验证。当前可见材料只有 A 包 3 张图、B 包 4 张图；C 包和完整标注真值均缺失。 |

## 需业务/主办方补充确认

1. 已取得《光伏自核材料及规则-v2.xlsx》并建立[逐项对照](官方材料规则对照.md)；仍需业务负责人确认阶段适用范围。高火险行业清单，以及行业加费或拦截的正式规则仍未提供。
2. 首期与中期的业务边界：裸露电缆检查、阶段二检查项分别在哪个阶段强制启用。
3. 官方组件型号与额定参数目录，以及风、雹、雪的指标口径、数据源、阈值和判定方式。
4. 监控覆盖优惠的有效性定义、证明材料、费率/折扣条件。
5. 完整 A/B/C 测试包、材料分类、视角标注、核保结论及风险点真值；以此校准图片质检阈值并验证赛题指标。

在这些资料到位前，系统采取“资料不全即显式未知、补件或转人工审核”的保守策略。不得将当前代码和单元测试表述为已通过比赛准确率验收。
